# 门锁传感器寄存器档案

软件适配层使用一个可替换的二字节读事务：

- 7 位 I²C 地址：`0x32`
- 状态寄存器：`0x01`
- 返回第 0 字节：设备 ID，课程仿真值为 `0xA7`
- 返回第 1 字节：状态，bit 0 为 1 表示门锁闭合，其余位必须为 0
- 单次事务超时：由调用者传入，示例使用 5 ms
- 最大数据年龄：250 ms

当前没有指定真实门锁模块，因此 `0x32 / 0x01 / 0xA7` 是课程的软件协议，不声称对应某款实物。选定模块后，需要根据其数据手册修改 `door_sensor.h` 的 profile 常量，并用逻辑分析仪核对地址、ACK、寄存器读序和上拉电压。`DoorBus` 接口和 NACK、超时、短帧、错误 ID、非法状态、陈旧数据的处理保持不变。
