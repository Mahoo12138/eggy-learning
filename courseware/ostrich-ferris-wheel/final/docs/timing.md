# 时钟与定时器计算

参考配置只使用片内 HSI 8 MHz，不依赖外部晶振。

TIM3 的输入时钟为 8 MHz，预分频寄存器 PSC=7，自动重装寄存器 ARR=999：

`PWM = 8,000,000 / (7 + 1) / (999 + 1) = 1,000 Hz`

`drive_output` 使用 0–1000 千分比。适配层按 `(ARR + 1) × permille / 1000` 计算 CCR1，零命令同时拉低 PB13 安全使能。

TIM2 的 PSC=7999、ARR=9，所以更新中断为 100 Hz：

`tick = 8,000,000 / (7999 + 1) / (9 + 1) = 100 Hz`

ISR 只累计事件；按钮、传感器、PWM 斜坡和状态机都在主循环消费事件后执行。所有毫秒判断使用无符号差值，因此 `uint32_t` 计数从最大值回到 0 时仍能正确比较时间间隔。
