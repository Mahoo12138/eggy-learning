# 故障优先级与恢复矩阵

同一轮出现多个异常时，监督器只发布一个最高优先级原因，并锁存首次原因。

| 优先级 | 条件 | 立即动作 | 自动恢复 |
| --- | --- | --- | --- |
| 1 | 急停输入有效 | PWM=0，安全使能=低，进入 FAULT | 否 |
| 2 | 门锁读数有效但未锁 | PWM=0，安全使能=低，进入 FAULT | 否 |
| 3 | 载荷超过进入阈值 | PWM=0，安全使能=低，进入 FAULT | 否 |
| 4 | 门锁读数无效或陈旧 | PWM=0，安全使能=低，进入 FAULT | 否 |
| 5 | 中断事件队列溢出 | PWM=0，安全使能=低，进入 FAULT | 否 |
| 6 | 本周期健康链不完整 | PWM=0，安全使能=低，进入 FAULT | 否 |

故障条件消失只表示“允许人工复位”，不会清掉锁存。清除必须同时满足：所有当前故障都消失、操作者发出 reset、控制器保持安全输出。复位后重新走 BOOT 与 SELF_TEST。
