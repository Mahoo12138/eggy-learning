## 给主报告的可支持结论

1. **在这些样本里，C++ 后台不是一个单一岗位族。**能区分音视频微服务、游戏服务、交易系统、数据库内核，以及接受 C++ 的 Go/AI 产品后台。因此学习路线应先选场景，不能只按语言归类。（依据 CB01–CB08）
2. **从应届到 1–3 年，交付责任的变化比语言名变化更清楚。**应届摘要出现参与、协助、学习；1–3 年摘要更集中于既有服务的功能维护、性能优化与工具/环境维护。此结论仅是小样本观察。（依据 CB01、CB05–CB08）
3. **AI 已出现在部分后台工作的业务对象及基础设施里。**CB04 明确是 AI 产品；CB03 是向量检索。它们不能证明所有 C++ 后台岗位都要求训练模型，也不能证明深圳普遍强制使用 Cursor、Copilot、Claude Code。（依据 CB03、CB04、AI-CB01–03）
4. **传统嵌入式转后台存在明确个案，但不能推出转型无门槛。**CB06 的接受转型文字是直接证据；其完整网络、并发、操作系统等门槛未取得。（依据 CB06）
