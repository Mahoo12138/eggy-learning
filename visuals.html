学习路线总览

训练建议，不是求职资格评定

先补 C 基础，再依次完成 whatforeating、终端迷宫、反应力游戏盒。共 32 个训练单元，每单元 4 次、每次 2–3 小时，可按课业顺延；三个项目依次推进。点击节点查看训练目标；实际计划、证据和复测在学习计划与进度中管理。

拖动平移；Ctrl / ⌘＋滚轮缩放。聚焦画布后可用方向键平移、＋/−缩放、0适配。实线是三个项目的训练顺序，虚线是交付后按需选择的深化方向。蓝色边框表示当前查看的节点；下方列表可直接选择节点。

节点列表（键盘与小屏幕替代）

    1. 单元 1–4，C 基础验收与补缺：输入、函数、数组、指针、字符串、固定容量记录与调试；通过的能力用证据确认，未通过才补练。
    2. 单元 5–12，whatforeating 今天吃什么：C + TUI，在 Windows / CLion 中从固定菜品表和基础随机练习开始，再做“换一个 / 确认”、本地结果文件与终端界面；正式随机策略尚未确定，训练实现不代表最终产品方案。
    3. 单元 13–20，C++ / Linux 终端迷宫：用现代 C++ 表达地图与游戏状态，完成移动、碰撞、存档与恢复，在 Linux 独立构建和调试。
    4. 单元 21–28，MCU 反应力游戏盒：同一块板、单 LED 与按钮，练非阻塞状态机、消抖、计时与串口记录；真机与仿真证据分开标注。
    5. 单元 29–32，复测与交付：按“任务 → 实际记录 → 证据 → 验收 → 延后复测”追溯；补独立变式、复现步骤和已知限制。
    6. 交付后才选深化：依据项目体验和目标 JD，选择 MCU 外设 / RTOS，或 Linux 设备应用 / C++ 后台；不把三个入门项目变成三条长期并行主线。
