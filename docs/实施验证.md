## 已执行的真实浏览器闭环

浏览器核验使用独立的临时数据副本和本地临时服务，未连接或改写正式 `data/`。实际完成了以下流程：

- 从蛋仔岛大厅进入第一关，依次完成预测、真实 C 编译运行、解释、引导修改和独立变式；完成后获得经验与星星，刷新页面后进度、奖励和当前关卡保持一致；
- 在独立挑战查看完整解法后提交，当前变式不授星，页面切换到服务端分配的等价变式；独立完成新变式后正常得星；随后又以空代码复验三层提示流程，确认答案只在 reveal 记录成功后出现、焦点进入答案区，刷新后改派未曝光变式；
- 在管理页查看对应的答题、代码、失败记录、提示与完整解法使用、独立变式和奖励档案；修改并保存本周游玩卡后，刷新仍能读取新状态；
- 打开鹅蛋作品页，确认没有证据时不能提交；填写作品证据并逐项独立自检后获得章节星星，下一章随即解锁；该流程记录的是学习者自检与证据，不代表系统自动验证了作品源码；
- 在乐园地图展开并读取段位详情，在课程工坊读取当前课程内容；页面展示与当前 v2 数据一致；
- 在 **390 × 844** 视口检查大厅、乐园地图、作品关和管理页，四页均无页面级横向溢出；本轮浏览器操作结束时 console error 为 **0**。

这轮浏览器闭环覆盖了学习者游玩、完整解法补救、作品章节、进度持久化、管理档案、周卡、地图和课程工坊。Boss 晋段以及六件作品的章节、奖励和晋段状态由领域测试模拟；作品源码和实际系统行为尚未验证，也没有在浏览器中伪装成已完成的真实作品验收。

## 后六段与硬件验证边界

目前的领域测试可以验证六件作品的章节、星星、Boss 与晋段规则，浏览器也验证了鹅蛋作品的证据必填、独立自检、得星和章节解锁。作品通过仍依赖学习者自检及提交证据，系统没有自动编译或语义验证后六段作品源码。

以下实现和实物行为尚未测试：

- `蛋仔美食街·今天吃什么`：完整 C 作品源码、真实文件处理、坏输入、边界数据和可复现构建；
- `蛋仔摩天轮安全中控站`：STM32 真机接线、外设、中断、定时、串口日志、复位与故障状态；
- `蛋仔岛夜班巡检台`：Linux 进程、文件描述符、管道、信号、异常退出与恢复；
- `蛋仔商城道具配送中心`：C++ 资源管理、线程同步、竞争条件、关闭流程与压力场景；
- `蛋仔游戏厅联机积分中心`：本地网络、断线/重连、重复请求、SQL 约束、SQLite 持久化与重启一致性；
- 无敌凤凰蛋自主作品：需求、架构、跨模块故障、可复现交付和他人接手。

因此，当前验证结论限定为：课程与进度规则、前三段在线 C 运行环境、数据接口和核心浏览器学习闭环已经验证；STM32 真机以及后续作品的完整源码、硬件和系统行为仍需在实际学习阶段逐项验收。
