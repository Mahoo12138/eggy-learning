## 页面接入与维护

共享布局样式在 [characters.css](../public/assets/characters.css)，由首页、学习者页和独立段位地图引入。角色大小和位置通过页面对应的样式控制；图片本身没有裁掉四肢、天线或道具。

- 角色用于欢迎、陪伴、荣誉、本周安排和页面状态。九阶仍是全局段位；角色不能替代 `public/assets/ranks/` 中的段位徽章，也不与某个段位一一绑定。
- 普通互动题继续围绕知识、代码和反馈，不因新增角色而加入乐园故事场景。当前 `play.html` 题目页与 `admin.html` 管理页未使用这批角色。
- 备用素材保持文件可查、用途可追踪。启用时同步更新本清单中的“当前用法”，避免把建议写成已实现功能。
- `references/` 中的原图保留为参考。后续重绘应输出独立透明副本，不覆盖原图；同时补充 `redraw-prompts.json` 中的提示词和参考文件路径。
- 检查透明性时应检查 Alpha 像素，而不只检查扩展名或是否含 Alpha 通道。含棋盘格像素的参考图不能作为已处理的透明 PNG 上线。
- 新增或替换角色后，检查桌面和手机宽度下的遮挡、留白、完整轮廓及按钮可点击性。装饰性角色使用空 `alt`；需要传达独立信息的角色提供简短、具体的替代文字。

素材清单记录资产和代码接入情况；运行时验证结果以当次实际检查为准。
