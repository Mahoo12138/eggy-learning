# 补星挑战

段位地图显示每章的练习完成状态和独立星星。已完成但尚未授星的章节有“补星挑战”入口，直接进入独立变式，不重做前面的训练。

鹌鹑蛋三章支持自动补题：输入换算、条件循环统计、函数合同。原变式均已看过答案且该章缺星时，服务端按曝光记录生成下一道稳定编号的参数题；不会修改课程文件或把整章版本重置。初始代码只保留框架，完整答案仍经 reveal 接口登记后才返回。参数题与原题共用同一章的授星键，每章最多获得一颗星。

查看新题答案后不授星，但会提供另一道题。错误代码、重复请求和反复提交都不刷星或完成经验。独立通过新题可补星；最后一颗星即使来自回访较早章节，也会推进当前已完成的学习位置到 Boss。Boss 必须达到原定星数才能进入。

验证覆盖：原题全部曝光、补题答案继续曝光、刷新后恢复未曝光题、旧 reveal 重放、缺少实现证据、C 用例包含空输入/正常/边界/非法/缺失输入、三章补齐三颗星、回访第一章取得最后一星、Boss 解锁、重复提交和课程版本不变。其他在线段位仍使用原有等价题库。
