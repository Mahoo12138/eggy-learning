#### 1. 安全进入和离开食堂终端

从空工程写出 TuiSession 生命周期。完整接入 VT 输出能力、备用屏、光标隐藏和经典事件输入所需模式，并让所有退出路径汇合到同一个清理点。

涉及文件：`CMakeLists.txt`、`src/main.c`、`src/app.c`、`src/app.h`、`src/platform/terminal_win32.c`、`src/platform/terminal_win32.h`

1. **建起可警告即错误的 C17 工程**：创建 Debug/Release x64 目标、/W4 警告级别和 app_run 入口；main 只负责把退出码返回给系统。
   - 文件：`CMakeLists.txt`、`src/main.c`、`src/app.c`、`src/app.h`
   - 验证：Debug 与 Release 均能构建，空应用返回 0，main.c 不包含业务或绘制代码。
2. **保存并切换控制台状态**：实现 TuiSession：保存原输入/输出模式；输出开启 processed output 与 VT；输入开启 extended/window input，关闭 quick edit、line、echo 和 processed input，不开启 VT input。
   - 文件：`src/platform/terminal_win32.c`、`src/platform/terminal_win32.h`
   - 验证：在 Windows Terminal 中启动后鼠标点击不会冻结输入，GetConsoleMode 失败时能给出可读错误。
3. **让每条路径都可靠还原**：发送进入备用屏、隐藏光标与样式复位序列；建立幂等 terminal_restore，并让普通退出、Ctrl+C 和逐点故障注入都走同一清理路径。
   - 文件：`src/main.c`、`src/app.c`、`src/platform/terminal_win32.c`
   - 验证：退出后回到原屏幕，光标可见，原输入输出模式逐位恢复；重复 restore 不产生副作用。

- 编译：`cmake -S . -B build -A x64`；`cmake --build build --config Debug`
- 操作：运行 eggy_canteen.exe，按 Q 退出。；再次运行并按 Ctrl+C。；依次打开三处初始化失败开关后重复启动。
- 预期：三类退出都恢复原控制台。；初始化失败不会遗留隐藏光标或备用屏。；程序在非控制台宿主中明确提示应使用 Windows Terminal 或真实控制台。
- 独立检查：独立补上‘进入备用屏之后失败’的故障注入点，并证明 restore 可重复调用且状态仍完整恢复。
- 证据：三次终端前后状态快照、故障注入输出和关键函数差异

- 操作：完成一次推荐→重抽→推荐→接受→查看→编辑。；删除有历史的菜再打开历史。；写入超过容量的动作并重启。

#### 14. 加入排除、去重和加权策略

在 RecommendQuery 中明确‘排除最近抽到’读取 lastRecommendedAt，‘排除最近接受’读取 lastAcceptedAt。去重状态按规范化查询签名保存；权重综合收藏、评分、久未接受并使用安全 64 位累加。

涉及文件：`src/core/recommend.c`、`src/core/recommend.h`、`src/core/model.h`、`src/ui/view_recommend.c`、`tests/test_recommend_strategies.c`

1. **实现两种语义明确的最近排除**：为 recommended/accepted 分别计算 cutoff；未有时间的菜可参与；恰好等于 N 天的规则固定为可参与并写入界面文案。
   - 文件：`src/core/recommend.c`、`tests/test_recommend_strategies.c`
   - 验证：固定时钟覆盖早于、等于、晚于 cutoff 及从未发生四类菜。
2. **完成按查询签名的无重复轮次**：规范化分类、排序后的标签和排除选项生成签名；一轮内移除已抽 ID，耗尽后只重置一次；菜单或条件变化建立新轮次。
   - 文件：`src/core/recommend.c`、`src/core/model.h`、`tests/test_recommend_strategies.c`

   - 文件：`src/core/recommend.c`、`src/ui/view_recommend.c`、`tests/test_recommend_strategies.c`
   - 验证：脚本 RNG 命中第一个、区间边界和最后一个；超大权重返回错误或安全归一化，全零退回均匀选择。

- 编译：`cmake -S . -B build -A x64`；`cmake --build build --config Debug`；`ctest --test-dir build -C Debug -R recommend_strategies`
- 操作：以固定菜单跑排除最近 7 天。；连续抽完一轮后再抽一次。；收藏一道菜并比较权重解释。
- 预期：排除文案与字段含义一致。；去重轮次按查询隔离。；权重边界、溢出和全零情况有确定结果。
