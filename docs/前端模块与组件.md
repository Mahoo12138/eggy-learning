# 前端模块与 Web Components

页面由浏览器直接加载 ES Modules，服务端按原样提供 `.js` / `.mjs` 与 CSS。启动、修改和部署都没有应用打包步骤；仍不需要 npm 安装。模块通过页面入口的相对路径 `import` 按需加载，不使用全量注册器。

## 已有 module 与 interface

| module | interface / 使用位置 | 集中的 implementation |
| --- | --- | --- |
| 代码高亮 `eggy-code` | `code`、`language`；示例、编辑输入、完整思路 | 按语言加载、着色、原生输入镜像、滚动 / 尺寸同步、IME 与异步渲染保护 |
| 选择输入 `eggy-select` | `setOptions(items, value)`、`value`、`disabled`；7 处选择输入 | 动态选项、文本转义、重复编号拒绝、原选择失效提示、原生表单 reset 与校验 |
| 本周游玩卡 `eggy-week-card` | `model`、异步 `save(payload)`；`week-saved` / `week-error` 事件 | 目标编码、休息状态、次数显示、提交保护、草稿保留、保存状态与重挂 |
| 声音与动效 `eggy-comfort-controls` | 现有两枚原生按钮；大厅与关卡 | 偏好订阅、文案与 ARIA、点击监听生命周期 |
| 通知提示 `eggy-notice` | `show(message, { kind, duration })`；大厅、关卡、管理页 | 安全文本、状态播报、替换计时器、断开清理；错误持续显示 |
| 课程模拟 `eggy-course-preview` | `show({ course, activityId, mode, dirty })`、`close()`；课程工坊 | 原生 dialog 模态与焦点、草稿快照、学习者页面载入、直接切题、重置与失败重试 |
| 共享偏好 `comfort.mjs` | 偏好读取、切换、订阅 | 同页多实例、跨页 storage、系统减少动效、存储不可用时的当前页状态 |

这些 module 使用 Light DOM，保留原生 `select` / `form` / `label`、键盘与已有 CSS 的行为。标签指向内部原生输入的编号，不指向 custom element。事件保持原生冒泡，页面可在 `eggy-select` 上监听 `change`，事件目标仍是原生 select。

### 选择输入

```html
<link rel="stylesheet" href="/assets/components/components.css">
<label for="rank-input">当前段位</label>
<eggy-select id="rank-picker">
  <select id="rank-input" name="rankId" required></select>
</eggy-select>
```

```js
import './components/select.mjs';

const picker = document.querySelector('#rank-picker');
picker.setOptions([
  { value: 'quail', label: '鹌鹑蛋' },
  { value: 'pigeon', label: '鸽子蛋' }
], 'quail');
```

`setOptions` 先校验全部编号再替换 DOM，重复编号不会破坏原选项。选中编号已不在列表时保留“已不可用”项，并使原生输入校验失败，用户必须重新选择；不会静默保存其他目标。调用时的选中值建立原生表单 reset 的基准。`disabled` 作用于内部原生输入；fieldset 禁用与 FormData 行为由浏览器保留。

### 本周游玩卡

`eggy-week-card` 包含一个原生 form。表单字段用 `data-week-field` 标记，模板和视觉由页面保留，行为由 module 集中管理：

- 必需字段：`playDays`、`mainGoal`、`shortLevelId`、`note`、`message`。
- 可选字段：`count` 输出次数、`weekStart` 展示自然周。
- `mainGoal` / `shortLevelId` 为选择输入 module；模式用 `input[name="mode"]` 的 `active` / `rest`。
- `scope="current-rank"` 使用当前段位、排除归档关卡并包含项目 Boss；`scope="all"` 保持管理者原有的全课程候选，不含项目 Boss。
- `model = { course, week, rankId?, learnerId? }` 载入一个快照。更新 model 是明确重新读取操作；普通 detach / reconnect 保留当前草稿。
- `save` 是页面提供的真实 HTTP adapter，返回已确认的周卡对象。module 集中形成 payload 并携带原 revision；保存期间阻止重复提交并禁用编辑。失败保留输入和旧 revision，成功采用服务器周卡。
- `week-saved` 的 `detail.weekCard` 通知页面刷新大厅或保存状态；`week-error` 的 `detail.error` 可供管理页显示冲突解释。

```js
import './components/week-card.mjs';
import { requestJSON } from './park-ui.mjs';

const editor = document.querySelector('#week-editor');
editor.save = async payload => {
  const response = await requestJSON('/api/play/week-card', {
    method: 'PUT', body: JSON.stringify(payload)
  });
  return response.data.weekCard;
};
editor.model = { course, week, rankId, learnerId };
```

学习者与管理者两个 adapter 保留各自的课程范围与页面文案。服务端继续负责 revision 冲突、校验、持久化、幂等、奖励与领域规则。界面 module 不获取隐式全局数据，也不重新计算奖励资格。

这条 seam 的 leverage 是两端复用完整编辑流程，locality 是模式、选择和提交状态集中。删除这个 deep module 后，这些行为会回流两页；仅包裹已有图片或普通文本的 shallow module 暂不新增。

### 代码高亮

`eggy-code` 支持 C、C++、Bash / Shell、JSON、JavaScript 和 SQL。`language` 属性或同名 property 指定语言；未知语言显示原文。`code` property 提供原始源码，不包含高亮标记。

```js
import './components/code.mjs';

const view = document.createElement('eggy-code');
view.language = 'c';
view.code = '#include <stdio.h>\nint main(void) { return 0; }';
document.querySelector('#code-container').append(view);
```

模块自行加载同源样式。也可以使用转义后的 HTML 文本作为初始源码；动态更新使用 `code` property。

已有原生编辑输入可以直接放入元素中：

```html
<label for="source-input">当前代码</label>
<eggy-code language="c">
  <textarea id="source-input" name="source" spellcheck="false">int main(void) { return 0; }</textarea>
</eggy-code>
```

组件在 textarea 后方显示着色镜像，保持原来的 value、label、选区、focus、readonly、disabled 和 FormData。输入时不重建 textarea；滚动与原生拖拽尺寸同步。中文输入法组合阶段显示原生文本，结束后重新着色；强制颜色模式使用系统颜色的原生输入。装饰镜像设置 `aria-hidden`，避免重复朗读。表单 reset 和元素重新挂载也保留原生行为。

语言加载与渲染采用版本检查，较早的异步结果不会覆盖新源码。超过 65,536 字符时保留原文并跳过着色；库或语言文件加载失败时原文仍可读可编辑，并通过 `code-highlight-error` 事件暴露错误。`data-highlight` 区分 `loading`、`highlighted`、`plain`、`oversize` 与 `unavailable` 状态。高亮不是语法校验，运行评分仍提交原始源码。

关卡页的运行示例、引导修改、独立变式和已授权展示的完整思路均使用这个 module；终端输出继续按纯文本显示。

### 课程模拟

课程工坊的“模拟学习”先采用当前编辑器的有效草稿，再把课程快照交给 `eggy-course-preview`，无需先保存课程。无效 JSON 会阻止打开弹窗并保留原文。组件内部以原生 `<dialog>.showModal()` 建立模态，关闭后回到原触发按钮；组件移除时清理 iframe、监听与载入计时器。

弹窗在同源 iframe 中复用 `play.html?preview=workshop` 和真实学习渲染，不维护第二套题型模板。父子窗口消息校验来源窗口与 origin，只有嵌入的预览模式接收课程快照。题目选择、上一题和下一题绕过答题顺序；作品章节、Boss、章内引导和独立检查也可自由查看。切题保留本次输入，重置或关闭会清空模拟状态。

模拟提交使用独立 `/api/admin/preview/attempt` 接口，共用正常关卡的评分与运行器，但不经过进度写入、奖励和幂等回执流程。模拟不读取真实尝试来恢复答案，也不写入作品引导的 localStorage 进度。正式学习路径继续遵循原有解锁与授星规则。服务仅对预览页面允许同源嵌入。

## 外部依赖

代码高亮采用同源托管的 `@highlightjs/cdn-assets@11.12.0` 浏览器 ESM；无需 npm 安装或打包。只加载核心和实际使用的语言规则，不做全量注册或自动语言猜测。C 的核心加规则共 25,289 字节（未压缩）；许可证、来源和 SHA-256 保存在 `public/vendor/highlightjs/`。其他 module 仍使用原生浏览器能力。

引入外部依赖时，应使用固定版本的浏览器发行物，核验传递依赖、MIME、CORS、CSS 与资源路径，并保存来源和许可证。优先同源托管；npm 标注“ESM”不保证传递依赖没有裸包名。需要 import map 时应处理现有 CSP 对内联脚本的限制。直接 CDN 导入需要针对实际来源调整 CSP，而不是关闭保护。

应用的“无打包器”约束独立于是否使用第三方 ESM；不需要为未来可能出现的第二个 adapter 先建立插件框架。历史招聘报告维持独立快照与既有图表实现。

## 验证

领域与服务器测试：

```sh
node --test
```

浏览器回归脚本使用已有 Playwright，独立外部浏览器窗口与临时 data 副本。不会向正式服务提交周卡或课程：

```sh
# NODE_PATH 指向现有 Playwright 安装的 node_modules；没有时先准备独立 QA 环境。
NODE_PATH=/path/to/node_modules HEADED=1 node scripts/verify-web-components.mjs
```

默认外部浏览器为 Microsoft Edge；`BROWSER_CHANNEL` 可切换已安装的 Playwright channel。`LIVE_URL=http://127.0.0.1:3000` 只额外检查正式服务加载新模块，`QA_OUTPUT` 指定截图目录。脚本自动清理数据副本，并比对正式 course / progress / week-card 在运行前后的文件内容。

覆盖两端真实 HTTP 保存、版本冲突、休息往返、网络中断与重复提交、原生表单 reset / FormData、失效选项、JSON 错误回滚、偏好重挂与跨页同步、通知计时替换、桌面和手机布局。刻意产生的 412 与网络中断日志单独列出，其他控制台错误仍令验证失败。

独立高亮验收命令：

```sh
NODE_PATH=/path/to/node_modules HEADED=1 node scripts/verify-code-highlight.mjs
```

它通过临时进度推进真实 C 示例与代码修改，检查提交源码、IME、异步切换、HTML 字符、滚动与尺寸、重挂、reset、未知语言、超长输入、强制颜色和依赖加载失败。不会写入正式学习数据。
